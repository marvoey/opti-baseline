Block Relationships & Logic

Rel A: Nav Block ↔ Prose Block

The Content: The right column is populated with ProseBlocks representing the dense content (e.g., extracted paragraphs on "European Expansion Requirements").

The Agentic Value: The left column is populated with a Nav Block. The AI automatically generates the links in the left column based on the H2/H3 headers of the Prose Blocks it placed in the right column. It serves as a real-time table of contents for the dynamically assembled document.

Rel B: Prose Block ↔ Media Block

The Content: Deep documentation often requires visual support.

The Agentic Value: The AI looks at the tags of the primary Prose Block. If it is tagged domain: digital_assets, the AI queries the DAM for a Media Block that shares the exact same tag and injects it. The text and visual aid are paired at runtime based on shared metadata, ensuring perfect contextual alignment.

Rel C: Content ↔ Compliance Block

The Content: Mandatory legal disclaimers.

The Governance Lock: If any block inside the layout is tagged with a regulated geography or domain (e.g., geo: canada), the layout must inject the corresponding Compliance Block. The compliance text is a direct, unavoidable consequence of the information being displayed.

Demo Scenario in Action

Trigger: "Summarize Canadian regulatory reporting for digital assets."

  1. AI detects the educate intent and provisions the 25/75 Sidebar Layout.
  2. Right Slot: AI fetches a Prose Block explaining OSFI rules.
  3. Left Slot: AI auto-generates a Nav Block mapping to the headers on the right.
  4. Compliance Lock: Layout detects geo: canada and forcefully locks the Canadian disclaimer at the bottom.

Developer Implementation Note

The components must be able to "read" each other's state or metadata.

The Left Column component cannot be a static HTML list. It needs to receive the JSON payload of the Right Column's contents, map over the headings, and generate anchor links. Similarly, the overall Layout wrapper needs a function to check the geo tags of its children to decide which Compliance component to render.
