# Routing

## proxy.ts — locale clean URLs

`proxy.ts` is the **Next.js 16 Proxy** (the replacement for `middleware.ts`).
It runs before every request that matches the `config.matcher` and handles
locale routing only — no data fetching.

### Three-branch logic

```
incoming path
      │
      ├─ first segment == DEFAULT_LOCALE ("en")
      │    → 307 redirect to strip it
      │      /en/slug  →  /slug
      │
      ├─ first segment is a KNOWN_LOCALE_SEGMENT (non-default CMS locale)
      │    → NextResponse.next() — pass through unchanged
      │      /fr/slug stays as /fr/slug; [locale] = "fr"
      │
      └─ anything else (clean URL, no locale prefix)
           → NextResponse.rewrite to inject default locale internally
             /slug  →  /en/slug  (invisible to browser)
             [locale] = "en"
```

`DEFAULT_LOCALE` comes from `OPTIMIZELY_DEFAULT_LOCALE` env var (default `en`).
`KNOWN_LOCALE_SEGMENTS` is imported from `lib/locales.generated.ts` (auto-generated
from the CMS via `npm run gen:locales`).

### Matcher

```
/((?!api|_next/static|_next/image|preview|admin|styleguide|favicon.ico|.*\\..*).*)
```

Excluded from the proxy (served as-is):

| Pattern | Reason |
|---|---|
| `api` | API routes bypass locale routing |
| `_next/static`, `_next/image` | Next.js internals |
| `preview` | CMS draft preview — must not be locale-prefixed |
| `admin` | Content type inspector — outside `[locale]` layout |
| `styleguide` | Block gallery — outside `[locale]` layout |
| `favicon.ico` | Static asset |
| `.*\\..*` | Any path with a dot — covers all static assets (`/logo.svg`, etc.) |

For full worked examples see `PROXY.md`.

## App Router routes

### CMS routes (under `[locale]`)

| Route | File | Notes |
|---|---|---|
| `/[locale]/` | `app/[locale]/layout.tsx` | Wraps `SiteChrome` around children |
| `/[locale]/[[...slug]]` | `app/[locale]/[[...slug]]/page.tsx` | CMS catch-all |

`app/[locale]/[[...slug]]/page.tsx` resolves content with `getContentByPath`.
It tries the clean path first, then the locale-prefixed path as a fallback, then
calls `notFound()`. Both `generateMetadata` and the page body share a single
Graph request per render via `React.cache`. See `ARCHITECTURE.md` for the full
request lifecycle.

Error and loading states:

| File | Handles |
|---|---|
| `app/[locale]/error.tsx` | Runtime errors within a locale page |
| `app/[locale]/loading.tsx` | Suspense fallback (shimmer skeleton) |
| `app/[locale]/not-found.tsx` | 404 within a locale path |
| `app/global-error.tsx` | Root-level error boundary (full document) |

### Preview

| Route | File | Notes |
|---|---|---|
| `/preview` | `app/preview/page.tsx` | CMS live preview; `getPreviewContent` + on-page edit overlays |
| `/preview` (layout) | `app/preview/layout.tsx` | Wraps `SiteChrome` |

Excluded from `proxy.ts` — no locale prefix injected.

### Admin

| Route | File | Notes |
|---|---|---|
| `/admin` | `app/admin/page.tsx` | Lists all registered content types |
| `/admin/[key]` | `app/admin/[key]/page.tsx` | Detail for one content type |

Uses `lib/cms/contentTypes.ts` (CMS Management API, OAuth client credentials).
Excluded from `proxy.ts`. No `SiteChrome` — raw admin interface.

### Styleguide

| Route | File | Notes |
|---|---|---|
| `/styleguide` | `app/styleguide/page.tsx` | Block gallery index |
| `/styleguide/[slug]` | `app/styleguide/[slug]/page.tsx` | Per-block detail page |

Reads source files at runtime for the code viewer. Excluded from `proxy.ts`.
No `SiteChrome`.

## Locale system

### Generated file

`lib/locales.generated.ts` is auto-generated by `npm run gen:locales`
(`scripts/generate-locales.mjs`). It exports:

```ts
export const DEFAULT_LOCALE = "en";
export const LOCALES: Locale[] = ["en", "fr", "sv", "ko", "ko-KR", "cy", "zh"];
```

**Do not edit manually.** Re-run `gen:locales` whenever you add or remove
locales in the CMS.

### Helper functions (`lib/locales.ts`)

| Function | Purpose |
|---|---|
| `LOCALE_SEGMENTS` | Array of non-default locale route segments (used by `proxy.ts`) |
| `findLocale(segment)` | Returns the matching `Locale` or `undefined` |
| `localeSegment(locale)` | Returns the URL segment for a locale (empty string for default) |
| `localizePath(path, locale)` | Prepends the locale segment to a path |
| `stripLocale(path)` | Removes a locale prefix from a path |

`LanguageSwitcher` uses `stripLocale` + `localizePath` to build locale-switched
URLs. It hides itself when only one locale is enabled.
