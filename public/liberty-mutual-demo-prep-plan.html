Demo app on your laptop (plain Node, no installs)

  • One server file plus one CSS file. Run it twice for two "sites": Agent Hub (port 4001) and LibertyMutual.com (port 4002).

This is the Express idea with the install step removed: the same simple routes and HTML templates, but on Node's built-in server. That also let me test it end to end here, using Graph responses copied from your live content.

The two new content types are created in the CMS screens instead (C1, C2). The only deploy left is X4, for live Mark.
