7 · CMS EditorApproved, auditable, reversible

What governs a change in Optimizely CMS

Roles and access rights

Opti ID roles map to Read, Create, Change, Delete, Publish and Administer, per part of the content tree.

Approvals

Sequences with any number of steps. Administrators can stop people approving their own changes.

Versions

Compare two versions side by side. Restore creates a new draft, so nothing is silently overwritten.

Change Log

Settings › Tools › Change Log. Filter by user, category and action.

Identity from sign-on

What you told us

You keep hosting your front ends. No user management on the platform. No CDP required.

Rules live on the content, so marketing sees and changes them in the CMS, and one function applies them everywhere so a card and a table never disagree.
