7 · CMS EditorApproved, auditable, reversible

What governs a change in Optimizely CMS

Versions

Compare two versions side by side. Restore creates a new draft, so nothing is silently overwritten.

Change Log

Settings › Tools › Change Log. Filter by user, category and action.

Approvals

Sequences with any number of steps. Administrators can stop people approving their own changes.

Roles and access rights

Opti ID roles map to Read, Create, Change, Delete, Publish and Administer.

Approval sequences and roles are configured per instance.

Compare two versions and Restore: restore creates a new draft, not a silent overwrite. Open Settings › Tools › Change Log and filter by user or action.

If configured, show the approval sequence with “prevent self-approval” (four-eyes). With approvals on, republishing an older version needs New Draft from Here plus approval, so even rollback is governed. Opti ID roles map to CMS access rights: Read, Create, Change, Delete, Publish, Administer. If these are not yet set up in the instance, describe them rather than demonstrate.

Docs: docs.optimizely.com/cms-saas (Approve content, Compare versions of content, View the change log, Set access rights).
