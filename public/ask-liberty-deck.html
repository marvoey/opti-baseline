Frame (3 min). Start on familiar ground: customers ask “does my insurance cover a rental?”, not in policy terms.

For a regulated insurer the risk is not a poor AI answer. It is an answer nobody approved. So the work is split: Mark understands, the CMS answers. If anything is unclear, out of scope or slow, the visitor still lands on an approved page.

Three things to remember

Trusted. Governed. Safe by design.

Trusted

Every line on screen is a CMS block, with its sources and a disclosure.

Governed

Business users control the questions, the routing, the AI switch and what is hidden. No engineering ticket.

Safe by design

Account, legal and off-topic questions go to safe pages. The site never stores the question text.

4 · Live AppThe rules behind the guardrails

Three rules, enforced by the site

0.6

Confidence floor

Below 0.6, or marked “Out of scope”, a question skips matching and goes to the fallback page.

7

Fields, from closed lists

Mark picks from closed lists. Only seven classification fields pass validation, and everything else is dropped.

0

Questions stored

The site never stores the question text. Only the classification is held briefly, in a draft that is deleted when read.

6 · Architecture ArgumentSecurity and resilience

No dead ends, nothing to leak

Resilient

  • If Mark is slow or down, approved keyword routing takes over and the card says so.
  • Editors set the timeout: 5 to 60 seconds, 20 by default.
  • The AI switch is a CMS setting, so there is no redeploy.

Locked down

  • The tool endpoint needs a bearer token, compared in constant time. It refuses everything if no token is set.
  • The browser route accepts same-origin requests only, with size limits and rate limiting.
  • Only seven classification fields pass validation. Text is trimmed and length-capped.
  • Reply drafts are never published and are deleted as soon as they are read.

An open contract. A question goes in and a classification comes back. The same integration point could use your own AI backbone (LibertyAir).

Only go deep if architects or security reviewers are in the room. The tool endpoint needs a bearer token compared in constant time and refuses everything if none is set. The browser route is same-origin only, with request size limits and rate limiting. Seven classification fields are allowed, and reply drafts are never published and are deleted when read.
