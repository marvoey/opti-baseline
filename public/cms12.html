02 / NO GRAPH? NO PROBLEM.

DEEP CMS 12 INSPECTION VIA CONTENT DELIVERY API V3.0

Because Shutterfly runs on CMS 12 without Optimizely Graph, Mark AI connects directly to CMS 12's native Content Delivery REST API v3.0 (EPiServer.ContentDeliveryApi.Cms) via custom Opal Tools (such as fetch_cms12_content).

check_circle What This Unlocks Without Optimizely Graph
  • Friendly URL Resolution: Pass any live Shutterfly path (e.g. /en/holiday-photo-books/) and resolve the full page model directly from CMS 12.
  • Nested ContentArea Expansion (expand=*): Automatically unrolls inline and shared blocks inside MainContentArea (Hero blocks, Product grids, Promo strips) in one REST call.
  • Hierarchy Traversal: Inspect children or ancestors of any Content ID to audit entire seasonal campaign trees.
  • Zero Additional Licensing or Sync Overhead: Queries the existing CMS 12 SQL / DXP database in real time via standard REST endpoints.

1. C# Block Type Model (HolidayPhotoBookHeroBlock.cs)

            
[ContentType(
    DisplayName = "Holiday Photo Book Hero Block",
    GUID = "8f4b2c10-9e32-4d1a-b821-7a9c1204e512",
    Description = "Seasonal promotional hero block for Shutterfly Photo Books",
    GroupName = "Shutterfly Seasonal Campaigns")]
public class HolidayPhotoBookHeroBlock : BlockData
{
    [Display(Name = "Promo Badge", Order = 10, GroupName = SystemTabNames.Content)]
    [CultureSpecific]
    public virtual string? PromoBadge { get; set; }

    [Display(Name = "Headline", Order = 20, GroupName = SystemTabNames.Content)]
    [CultureSpecific]
    [Required]
    public virtual string Headline { get; set; } = string.Empty;

    [Display(Name = "Subheading Copy", Order = 30, GroupName = SystemTabNames.Content)]
    [CultureSpecific]
    public virtual XhtmlString? Subheading { get; set; }

    [Display(Name = "Primary CTA Text", Order = 40, GroupName = SystemTabNames.Content)]
    [CultureSpecific]
    public virtual string? PrimaryCtaText { get; set; }

    [Display(Name = "Primary CTA Url", Order = 50, GroupName = SystemTabNames.Content)]
    public virtual Url? PrimaryCtaUrl { get; set; }
}

            CMS 12 CONFIGURATION (NO GRAPH REQUIRED)
            
          


          
// 1. Install NuGet Packages
dotnet add package Optimizely.Cms.OpalChat
dotnet add package EPiServer.ContentDeliveryApi.Cms

// 2. Register in Startup.cs / Program.cs
public void ConfigureServices(IServiceCollection services)
{
    services.AddCms();
    services.AddOptimizelyIdentity();
    services.AddOpalChat(); // Enables Mark AI Chat Drawer in CMS 12 UI

    // Enables REST API v3.0 so Mark tools can inspect pages/blocks without Graph
    services.AddContentDeliveryApi(options =>
    {
        options.SiteDefinitionApiEnabled = true;
    });
}

// 3. Configure appsettings.json
{
  "EPiServer": {
    "Cms": {
      "OptimizelyIdentity": {
        "Authority": "https://login.optimizely.com/oauth2/default",
        "InstanceId": "<YOUR_INSTANCE_ID>",
        "ClientId": "<YOUR_CLIENT_ID>",
        "ClientSecret": "<YOUR_CLIENT_SECRET>"
      }
    }
  },
  "Optimizely": {
    "OpalChat": {
      "InstanceId": "<YOUR_INSTANCE_ID>",
      "ServiceUrl": "https://opal-backend.optimizely.com"
    }
  }
}
