Step 1 · Prompt

Paste the JSON. Ask it like a bug report.

Here's the Content Delivery API v3.0 response for page 1042 (Holiday Photo Books). On mobile, the 50% Off badge is missing and an "Excludes Disney Collection" line shows up. Desktop and tablet are fine.

Walk the full block tree, compare each block's controlTab to its deviceTabs, and tell me:
- which block and which device tab cause it, with the path from the page down
- every property that differs from controlTab, plus any keys that don't belong
- the fix in the CMS editor, and what the corrected JSON should look like

No setup. The payload and a clear question.

BonusSketch, not in the repo

Then stop it happening again

import { z } from 'zod';

const DeviceTab = z
  .object({
    inheritFromControl: z.boolean(),
    showPromoBadge: z.boolean(),
    overridePriceText: z.string().nullable(),
  })
  .strict(); // rejects keys like hiddenLegacyBannerId

A strict schema rejects the rogue key in CI, before it reaches a launch.
