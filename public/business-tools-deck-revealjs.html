Where should business users work?

dashboard

Directly in the CMS

For most editors and marketers, the CMS should be the single pane of glass. Optimizely's UI is designed to be intuitive enough that specialized external tools often aren't necessary.

api

Through Custom Tools

For highly specialized workflows (like heavy PIM/Merchandising syncs), you can build external tools that interact seamlessly with the CMS via Optimizely Content Graph and Management APIs.

A common question we get is whether business users should work directly in the CMS or if you need to build custom, external tools for them. The short answer is: both, depending on the role. For day-to-day tasks and content editing, Optimizely's UI is robust and acts as a single pane of glass. But for highly specialized workflows, like heavy PIM syncs or bespoke merchandising tools, our API-first architecture lets you build external tools that plug right into the platform.

Identifying pages with missing metadata

search_insights

1 The Query

Use Optimizely Content Graph (GraphQL) to instantly query the entire repository for products or pages where seoDescription is null.

2 The View

Surface these results in a custom dashboard right inside the Optimizely UI using a custom gadget, or export them to your external SEO tool.

3 The Action

Editors click directly from the dashboard report into the specific CMS page to update the metadata immediately.

Let's look at a concrete example you asked about: finding pages with missing metadata. Using Optimizely Content Graph, you can query your entire repository instantly using standard GraphQL. You can then surface these results in a custom dashboard right inside the CMS UI. This means your editors can see the report, click the offending page, and fix the metadata immediately, without ever leaving their workflow.

When it comes to bulk updates—say you're doing a massive Summer Sale where content changes across 100 pages—Optimizely handles this natively through a feature called 'Projects'. Projects let you group all those updates, preview your entire site in that future state, and publish them all simultaneously. If you're looking for true programmatic find-and-replace, you can achieve that through our Content Management APIs or by plugging a lightweight UI add-on directly into the CMS.
